## 比对中修复的问题

| 问题 | 修复 |
| --- | --- |
| 会话列表竞态（存量缺陷）：URL 参数切换项目时，store 旧项目的慢响应覆盖新项目会话，偶发「有会话项目显示空态」 | `fetchConversation` 加请求代际守卫，过期响应丢弃 |
| 笔记详情接口返回 snake_case（与列表接口 camelCase 不一致，存量问题） | 前端 clientLoader 归一化（零后端改动约束） |
| 笔记「所属项目」Select 显示原始 id / 选项为空 | `getWorkspaceList` 返回 `[err, res]` 元组误当响应体（08/09 两处），改元组解构 |
| 新建笔记预建空行被服务端 400 拒绝（content is required） | 改为进编辑器新建态，保存时才落库（与 F2 行为一致） |
| workspaceId 序列化残留（''/'undefined'）触发「workspace not found」 | clientAction 剔除假值并数值化 |
| leftbar-b 双模块实例：react-router 插件加载布局路径与页面别名导入形成两份模块，页面 setNav 落到默认 no-op context | context 抽独立模块 `leftbar-nav.ts`，两侧引用同一实例 |
