Aura 前端改造方向草图

这不是最终视觉稿，而是先把“功能更聚合、布局更新、体验更顺”的三种产品结构放在一起比较。

A

项目工作台优先

把 workspace 作为主对象：左侧是项目，主区是项目概览，聊天/笔记/任务都围绕当前项目展开。

适合解决

  • 功能松散
  • workspace 不像项目容器
  • 新用户不知道从哪里开始
B

三栏沉浸式推进

左项目，中间对话，右侧项目记忆/笔记/待办。核心体验是“一边聊，一边沉淀”。

Workspace
沉淀

适合解决

  • 聊天和笔记断开
  • 对话结果没有资产化
  • 每天使用效率低
C

文档化项目空间

把 Aura 更靠近“项目档案”：顶部切换概览/聊天/笔记/任务，信息稳定、可归档。

项目库
概览
聊天
笔记
任务

适合解决

  • 长期项目资料管理
  • 清晰、克制、稳定
  • 降低布局复杂度
我的初步推荐：B 为主，A 为入口。 首页进入“项目工作台”，选中项目后进入三栏推进界面。这样既能解决功能松散，又能把 Aura 的产品主线变成“对话 -> 沉淀 -> 下次继续”。
