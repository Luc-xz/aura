  共用同一 confirmDelete。
- **工作台搜索与排序**：工具栏新增搜索框（400ms 防抖，B2 LIKE 供数，`%_!` 字面量由后端转义）与排序 Select

  「N 条对话」（chatCount，B1/B2 实时计数）。

  输入框）；`historyLoaded` 标记避免历史加载前闪现引导。

  中文化（user.js，凭据错误统一「账号或密码错误」，避免账号枚举）；workspace 删除 409 同步中文化
  （「请先将项目归档，再进行删除」）。
- **提交态**：登录/注册按钮接 React Router `useNavigation().state === 'submitting'` → loading + 禁用；
  工作台弹窗 confirmLoading 在 F1 已接。
